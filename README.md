# Flip Ledger
Книга сделок и ремонта (PWA): расходы по объектам, группировки, история цен материалов, маржа / налог / риелтор.

- `index.html` — приложение, `data.js` — данные расходов по объектам, `sw.js` + `manifest.json` — PWA.
- Установка: Android — Chrome → «Добавить на главный экран»; iPhone — Safari → «Поделиться» → «На экран Домой».
